# Networking Notes

## Локальный запуск

При локальном запуске `127.0.0.1` означает хостовую машину.

## Ошибка внутри контейнера

Внутри контейнера `127.0.0.1` означает сам контейнер.

## Правильное взаимодействие контейнеров

Контейнеры должны общаться через:

```text
http://product-service:8000
http://discount-service:8000
```
